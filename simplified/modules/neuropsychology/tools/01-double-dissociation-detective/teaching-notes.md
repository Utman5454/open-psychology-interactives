# Teaching notes - Double Dissociation Detective (Simplified)

`simplified/modules/neuropsychology/tools/01-double-dissociation-detective/`

**What it teaches.** Evidence for a double dissociation has to accumulate
in a specific order. One person worse on one task leaves the rival
explanation standing, that the task is simply harder. A second person
worse on the same task only adds severity, not logic. Only a reversal,
one person worse on task A and the other worse on task B, rules the
rival out. The fourth file shows the same four scores reclassify from
no evidence to a double dissociation purely because test length
improves precision.

**Before students start.** Read the "these are not patients" note: every
person, task, score and control group is invented.

**What students do.**
1. Work through four fixed cases, plotting each score against its own
   control group and choosing a verdict from the same four-option
   scheme each time.
2. On case 4, drag a slider for items per task and watch the verdict
   change while the scores stay fixed.
3. Read the closing diagram comparing what each shape of evidence
   rules out.

**What to look for.** Case 2 is the trap: two people, both further below
controls on delayed recall, looks like stronger evidence than case 1,
but it is still only a severity difference. Case 3 is the real
reversal. On case 4, the verdict moves from "not enough evidence" to a
single dissociation around 50 items, then a double dissociation from
about 55, while the four percentages never move.

**Debrief.** In case 2, what does the second person add if not logic?
In case 4, what changed if the scores did not?

**Common misconception / caution.** "Two people and two tasks" is not
automatically a double dissociation, which is exactly what case 2 is
built to catch. A reversal rules out one task simply being harder; it
says nothing about anatomy, and no lesion, region or brain area is
mentioned anywhere in this activity.

**Use in class / timing.** The four cases with the synthesis run to
about 6 to 7 minutes.
