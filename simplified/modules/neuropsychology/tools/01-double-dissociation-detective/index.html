What the evidence bought

Why a reversal is worth more than a bigger gap

Every file had one rival explanation to beat: that one task is simply harder than the other. Only one shape of evidence beats it.

Key idea: A single dissociation shows that two tasks come apart. It cannot rule out that one task is simply harder, and a second person with the same pattern does not help: that adds severity, not logic. A reversal does rule it out, because a task cannot be more demanding for one person and less demanding for another. That one piece of logic is the whole contribution of a double dissociation.

Two limits on that inference. The first you have just watched: a crossover in the point estimates is not a crossover in the evidence, and test length decides which you have. The second the numbers cannot reach at all: two tasks always differ in more than the process of interest, so a clean reversal on tasks that differ in several ways does not tell you which difference produced it. A double dissociation establishes that at least partly separable processing exists. Where that processing sits is a different question, and none of these files touches it.
