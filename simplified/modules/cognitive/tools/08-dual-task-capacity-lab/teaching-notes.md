# Teaching notes - Dual-Task and Limited Capacity Laboratory (Simplified)

`simplified/modules/cognitive/tools/08-dual-task-capacity-lab/`

**What it teaches.** Combining two simple tasks usually produces an
asymmetric cost: one task is protected much more than the other, even
though both are running at the same time.

**Before students start.** None needed. The three blocks run in a fixed
order automatically.

**What students do.**
1. Run the letters-alone block.
2. Run the sides-alone block, which starts automatically afterwards.
3. Run the combined block, answering both tasks on every trial.
4. Compare the paired bars: pale for alone, dark for together.

**What to look for.** One task usually takes a much bigger hit than the
other when they are combined, even though both are simple on their own.

**Debrief.** Which task took the bigger hit when combined? Does a task
costing more tell you it needs more attention when performed alone?

**Common misconception / caution.** Do not let "both got worse, so it
must be one shared pool" stand: a protected task alongside a costly one
is still compatible with more than one account. The combined block
always runs last and browser timing is not lab-grade, so treat the size
of these costs loosely.

**Use in class / timing.** Three short blocks, done back to back, take
6 to 8 minutes.
