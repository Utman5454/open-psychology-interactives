# Teaching notes - Stroop Interference Laboratory (Simplified)

`simplified/modules/cognitive/tools/06-stroop-interference-lab/`

**What it teaches.** Interference and facilitation are two separate
effects measured against a neutral baseline. Naming an ink colour is
slowed by a conflicting word and helped by a matching one.

**Before students start.** The prediction question is not built into
this page, so ask it aloud first: where will the neutral condition land
relative to the other two?

**What students do.**
1. Run six practice trials with feedback.
2. Run the 45-trial scored block, 15 trials per condition, with no
   feedback until it ends.
3. Read interference and facilitation off the results panel, both
   measured against neutral.

**What to look for.** There is no worked example on this page, so the
pattern has to come from the block itself: incongruent trials should run
slower than neutral and congruent trials a little faster, with neutral
in between. Watch for students reporting only the
incongruent-minus-congruent gap, which hides that it is two effects
moving in different directions.

**Debrief.** What can you say with the neutral condition on the chart
that you could not say without it? Interference and facilitation are
rarely the same size in one person's data. Does that difference mean
anything about that person?

**Common misconception / caution.** Students often reduce the Stroop
effect to "incongruent minus congruent," which throws away the
comparison neutral makes possible. Fifteen trials per condition is still
not enough for a stable difference score, and no reaction time on this
page is a Stroop score for the person who produced it.

**Use in class / timing.** Practice and the scored block together run
about 5 to 7 minutes.
