# Inattentional Blindness — Simplified Edition

**Module:** Cognitive Psychology
**Duration:** 4–5 minutes
**Level:** First year upwards
**Edition:** Simplified. The longer version adds four display variants, a table
of what each design change alters and a challenge on which change should
matter. It is at `modules/cognitive/tools/03-inattentional-blindness/`.

## Read this before you set it

**The demonstration works once per person.** Everything below the fold is
hidden until the recognition question has been answered, and no word above the
task mentions a second object, so a learner who works through it in order
cannot spoil it by scrolling.

Two things are outside the page's control:

- **The activity's name.** A student who already knows the term
  "inattentional blindness" arrives knowing that something will appear. The
  page cannot fix that without lying about what it is, and the catalogue
  cannot list it under a false name. If your group is likely to know the term,
  send them the link without the title, or run it projected.
- **Anyone standing behind them.** One screen, one naive observer.

If you want to see the design yourself first, use the **Running this session?**
button. It reveals everything and says plainly that it has spent that screen; a
page reload gives a fresh start.

## Learning objectives

By the end, a student should be able to:

1. describe, from having done it, a fully visible object going unreported;
2. distinguish attention from awareness;
3. explain why not reporting is not the same as not seeing;
4. say why the result is about the display and the task, not the person;
5. explain why the demonstration cannot be repeated on the same observer.

## Suggested use

**Projected, once, with the room counting silently.** Take the count from a
show of hands before you ask the second question. Then ask the second question
and watch the room.

**Set individually as preparation**, with an instruction to do it before
reading anything else about the topic.

**As the opening of a session on attention**, immediately before the
theoretical material, so the phenomenon is in the room before the vocabulary
is.

## Prediction question

Do not ask one about the demonstration; any prediction gives it away. If you
want a commitment beforehand, ask about the count instead:

> How hard can it be to count a few triangles among fifty shapes?

## Activity sequence

1. Instructions: count the solid down-pointing triangles. Nothing else is
   mentioned.
2. The display appears. It is static, self-paced and has no time limit.
3. The count is submitted and the display is hidden.
4. One question: was there anything else on that display?
5. The same display returns with the counted triangles ringed in one style and
   the unasked-for object ringed in another and labelled, plus the count
   against the true number.

## Debrief questions

- The object did not move, was never brief, and there was no time limit. What
  was actually preventing it from being reported?
- Is "I did not see it" the same claim as "I did not report it"? How would you
  tell them apart?
- What would you change about the display to make the object more likely to be
  reported? What does each change tell you about the mechanism?
- Someone in the room did report it. What does that tell you about them?
- If you ran this on the same person tomorrow, what would you be measuring?

## The moment worth stopping on

The last two. A student who reported the object often takes it as evidence
about themselves, and a student who did not sometimes takes it badly. Neither
reading survives contact with the design: a single trial on one display with
one count is not a measurement of a person, and the honest answer to "what
does this say about me" is nothing at all. Say it out loud.

## Likely misconceptions

**"I would have seen it if I had been paying attention."** Attention is
exactly what was occupied. That is the demonstration, not a failure of it.

**"It was hidden, or too small, or too brief."** It was none of those, and
the replay is the proof: same display, nothing moved.

**"This measures how observant I am."** It does not. One trial, one display,
one task.

**"So people are blind to what they are not attending to."** Too strong. The
task cannot separate an object that never reached awareness from one that
reached it and was not remembered a few seconds later, and that distinction is
still argued over in the literature. Both are consistent with what happened
here.

**"Most people miss it."** The activity deliberately reports no noticing rate,
because this collection has no data on how often people miss these objects.
Resist the temptation to supply a number from memory.

## Limitations and cautions

- This is a single trial. Nothing about it supports a claim about a person.
- A static array is not the video paradigm the finding is famous for. It
  produces a comparable phenomenon and is used in the applied literature, but
  the two designs are not interchangeable and differ in what else they load.
- Whether the object failed to reach awareness, or reached it and was
  forgotten, is not settled by this design and is not settled in general.
- The activity reports no rates of any kind, and inventing one would be worse
  than reporting none.
- After one run the observer is no longer naive. A second run demonstrates how
  the design works; it does not test whether they would have missed it.

## Accessibility

The display is static: nothing moves, flashes or changes, and there is no time
limit, so there is nothing for a reduced-motion setting to switch off. Shape
and fill carry the task and colour never does; every item is drawn in one
colour. The display carries a description saying what is on it and what to
count, written so that it does not give the demonstration away, and the replay
carries its own description naming everything marked. Keyboard operable
throughout, and the count accepts Enter. The recognition question is a report:
there is no correct answer and nothing is marked.

## Extension

Ask what the smallest change to the display would be that you would expect to
change the outcome, and why. Then ask what evidence would decide between "it
never reached awareness" and "it reached awareness and was forgotten". The
second question is the interesting one and the design cannot answer it.

## Evidence and reading

The video-based demonstrations are the famous ones; the static-array version
here is closer to the applied work on expert readers missing out-of-place
objects in medical images. Point students at that literature and at the
inattentional blindness versus inattentional amnesia debate, which is where
the "not reporting is not not seeing" caution comes from.
