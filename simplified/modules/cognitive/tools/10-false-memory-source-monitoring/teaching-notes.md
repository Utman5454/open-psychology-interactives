# Teaching notes - False Memory and Source Monitoring (Simplified)

`simplified/modules/cognitive/tools/10-false-memory-source-monitoring/`

**What it teaches.** A single word related to a list's theme can be
falsely remembered as heard, with real confidence and even attributed to
the wrong speaker, showing that recognition, confidence and source are
three separate judgements rather than one.

**Before students start.** Say nothing about the two critical words
beforehand. That silence is the whole design.

**What students do.**
1. Watch two short lists of ten words, each read by a named person.
2. For 10 test words, say whether you heard it, how sure you are, and
   if so, who said it.
3. Read your own personalised result, which names any lure words that
   fooled you.

**What to look for.** Watch for a student confidently endorsing one of
the two critical words, never actually presented, and attributing it to
a specific speaker.

**Debrief.** What did the word you falsely remembered have in common
with the list it seemed to belong to? You said a specific person said
it. Where did that detail actually come from?

**Common misconception / caution.** "This proves memory is unreliable"
overreaches: the intrusion is tightly constrained to a word that fits
the list's theme. This is one run for one student, so a single false
memory here says nothing about that student's memory in general.

**Use in class / timing.** Both lists and the test together take about
5 to 7 minutes.
