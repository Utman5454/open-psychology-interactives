# Teaching notes - Working-Memory Load Laboratory (Simplified)

`simplified/modules/cognitive/tools/09-working-memory-load-lab/`

**What it teaches.** Holding items in mind while doing a concurrent task
from the same domain costs more than doing one from a different domain,
and that cost grows with how much is being held.

**Before students start.** The two concurrent tasks are matched for
pacing, not for difficulty.

**What students do.**
1. Run two practice trials with the answers shown.
2. Run the block: hold a row of letters, answer four paced judgements,
   then pick the held letters out of a grid.
3. Read the two-line chart, one line per concurrent-task domain,
   accuracy against how much was held.

**What to look for.** The word-judgement line drops much faster from the
lower load to the higher one than the pattern-judgement line does, even
though both interrupt at the same pace.

**Debrief.** Why would an interruption from the same domain cost more
than one from a different domain, at the same pace? Would you expect
that gap to be the same size at both loads tested?

**Common misconception / caution.** Do not let "the harder-sounding task
must be doing the damage" go unchallenged: both concurrent tasks are
matched for pacing, not difficulty, so the cost is about domain overlap
rather than which task feels harder. Five trials per cell is a small
sample, so read the shape of the two lines rather than the exact
numbers.

**Use in class / timing.** Two practice trials and the block together
take 6 to 8 minutes.
