# Teaching notes - Visual Search Laboratory (Simplified)

`simplified/modules/cognitive/tools/02-visual-search-laboratory/`

**What it teaches.** Searching for a target defined by one feature barely
slows down as more items are added. Searching for a target defined by two
features together, tilt and colour, gets much slower with every item
added.

**Before students start.** The target is always present here, a
simplification worth naming before students start comparing the two
lines.

**What students do.**
1. Run six practice trials mixing both search types.
2. Run the 48-trial block, saying which half of the display the target
   is in.
3. Read the two search functions on the chart, one close to flat, one
   climbing.

**What to look for.** The conjunction line climbs across the three set
sizes tested while the feature line stays close to flat. That gap is the
whole finding: the same eyes, the same target, a very different cost per
added item.

**Debrief.** Why would adding items barely slow one kind of search but
slow the other a lot? Every display here contains a target. What might
that hide about ordinary searching, where it often does not?

**Common misconception / caution.** A flat line does not mean nothing was
checked, and a climbing line does not prove items were checked one at a
time; both stories fit two slopes equally well. Eight trials per point is
few, so treat the two lines as a demonstration of the pattern rather than
a precise measurement.

**Use in class / timing.** Practice and the block together take 5 to 7
minutes.
