# Teaching notes - Thematic Analysis Coding Laboratory (Simplified)

`simplified/modules/research-methods/tools/05-thematic-analysis-coding-lab/`

**What it teaches.** A code is an analytic decision made from a stated
position, not an extraction, so the same extract can support genuinely
different, defensible codes.

**Before students start.** None needed. Leaving the code blank is
allowed, and it can help to mention that in advance.

**What students do.**
1. Write your own code for the extract, or leave it blank.
2. Compare your reading against three prepared passes over the same
   extract.

**What to look for.** The three passes read the same few lines
completely differently, and none of them is presented as the right
answer.

**Debrief.** On what grounds could a reader reject one of the three
passes rather than another?

**Common misconception / caution.** "We should calculate inter-rater
reliability" is worth heading off here too: reflexive thematic
analysis is judged by the coherence of the analyst's reasoning, not by
agreement between coders.

**Use in class / timing.** Coding the one extract and comparing passes
takes about 4 to 5 minutes.
