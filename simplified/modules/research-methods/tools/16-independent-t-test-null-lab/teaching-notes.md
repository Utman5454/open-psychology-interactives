# Teaching notes - Independent-Samples t-Test: The Null Distribution (Simplified)

`simplified/modules/research-methods/tools/16-independent-t-test-null-lab/`

**What it teaches.** The same population gap gives a small,
unremarkable t at a small sample size and a large, clearly significant
one at a large sample size, holding the gap itself fixed.

**Before students start.** None needed. There is one fixed
significance level throughout, so there is no selector to explain.

**What students do.**
1. Set the difference between the means, the shared spread, and the
   number of people per group.
2. Press "run the same finding on more people" and compare t, p and d
   before and after.

**What to look for.** d stays the same when the sample size toggles
from 15 to 100; only t and p change, since they depend on how much
evidence there is, not on the size of the gap.

**Debrief.** Which of the three numbers, t, p or d, tells you about
the size of the gap, and which tell you about the evidence for it?

**Common misconception / caution.** A bigger sample turning a result
significant is not the same as the effect getting bigger; d is the
number to check before believing that.

**Use in class / timing.** Running the finding at both sample sizes
takes about 5 to 7 minutes.
