# Confidence Interval Laboratory — Simplified Edition

**Module:** Research Methods · **Duration:** 6–7 minutes · **Level:** Second year
**Edition:** Simplified, and narrower than its parent. This is the coverage
half. The second experiment, in which four fictional trials are judged against
a smallest-change-that-matters threshold, stays in the longer version at
`modules/research-methods/tools/09-confidence-interval-laboratory/`.

## Learning objectives

Students should be able to describe coverage as a property of the procedure;
predict what sample size and spread do to width; explain why neither changes
coverage; explain why a single interval either contains the truth or does not;
and say why the common probability sentence is wrong.

## Preparation

None. The true value is 12 and is on screen throughout.

## Suggested use

**Projected, in four minutes.** Run 1000 studies at 95 per cent. Then change
the sample size and run 1000 more. Ask what changed.

**Immediately before students report an interval of their own.**

## Prediction question

> A study reports a 95 per cent confidence interval. What is the 95 per cent a
> statement about?

## Activity sequence

1. Run 1000 studies at the defaults. Coverage lands near 95 per cent.
2. Raise the sample size. Width halves; coverage does not move.
3. Raise the population spread. Width doubles; coverage does not move.
4. Change the confidence level. Coverage follows it, bought with width.

## Debrief questions

- Which control changed coverage? Which changed only width?
- Run one study. Does its interval contain the truth? How would you know
  without the line being drawn?
- Why is a 99 per cent interval not simply better than an 80 per cent one?
- Why does every interval in a run have the same width here, and why would
  that not be true in a real study?

## The moment worth stopping on

Running a single study after a thousand. The one interval either covers or it
does not, and in real work the line is not drawn. That is the difference
between the procedure's long-run property and the thing in front of you, and
it is the reason the usual sentence about a 95 per cent chance is wrong.

## Likely misconceptions

**"There is a 95 per cent chance the true value is in this interval."** The
sentence the activity names as wrong.

**"A bigger sample gives better coverage."** It gives a narrower interval at
the same coverage.

**"A narrow interval is a good interval."** Narrow and centred in the wrong
place is worse than wide and honest; see the sampling bias activity.

**"99 per cent is safer."** It is wider. Whether that is better depends on
what the interval is for.

## Limitations and cautions

Sigma is treated as known because the simulation states it, which is why every
interval has the same width and why the multiplier is a normal quantile. A
real study estimates it and uses t, which widens intervals at small samples
and makes widths vary. Coverage is exact here only because the model is
exactly right; real coverage degrades when the assumptions do. The activity
says nothing about whether an interval is *useful*, which is the second
experiment in the longer version.

## Accessibility

Keyboard operable throughout. Intervals that miss are drawn dashed rather than
merely recoloured, so the distinction survives greyscale. The figure marks the
true value with a labelled line and its description states the level, the
counts and the coverage. All three headline figures are text. No timed content
and no motion.

## Extension

Set the level to 80 per cent and ask how often the reported interval will
mislead. One study in five is a number that changes how students read a
figure.

## Evidence and reading

Any estimation text on coverage, plus the literature on misinterpretation of
confidence intervals, which documents how widespread the wrong sentence is
among researchers as well as students.
