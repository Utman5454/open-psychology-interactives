# Teaching notes - Confidence Interval Laboratory (Simplified)

`simplified/modules/research-methods/tools/09-confidence-interval-laboratory/`

**What it teaches.** A 95% confidence interval describes how often the
procedure catches the true value across repeated samples, not the
chance that one interval contains it.

**Before students start.** The true value here is known only because
the tool built the population that way.

**What students do.**
1. Set the confidence level, sample size, population spread and seed.
2. Run studies repeatedly, adding to the same pile, and watch what
   share of the intervals catch the true value.

**What to look for.** Running enough studies to build up a pile of a
few hundred settles the hit rate close to the confidence level chosen,
while changing sample size or spread only changes how wide each
interval is.

**Debrief.** Complete honestly: "X% of the time, this procedure...".

**Common misconception / caution.** "There's a 95% chance the true
value is in this interval" is the claim to correct: once drawn, an
interval either contains the true value or it does not.

**Use in class / timing.** Building up a pile large enough to read
takes about 6 to 7 minutes.
