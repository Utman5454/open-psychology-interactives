Stimulus stage and comparison values

.stage is a fixed-height area where something is shown. If what appears there is timed, the activity must also offer a route that is not — a replay, a step control, or a static version carrying the same information. .peers shows a small set of values for comparison; where they are simulated, say so beneath them.

Pattern

Controls and entry

.controls and .control for activities that manipulate something rather than choose between options. bindRange in workbook.js keeps the <output> in step with its slider. .entry is a label, a small input and a button on one line; .entry__error is referenced from the input with aria-describedby, so a validation message is read as part of the field rather than appearing silently beside it.
