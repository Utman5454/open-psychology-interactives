Which conclusion is warranted?

Prejudice is not directly observable, so researchers operationalise it through measurable indicators such as self-report, reaction time and behaviour. Each is an imperfect proxy for the underlying construct.

Different measures answer different questions

No single instrument automatically tells us what a person thinks, feels, associates and does across every setting.

Key idea: A measure does not simply reveal “how prejudiced” someone is. It operationalises a particular part of the problem, and conclusions should stay within what that evidence can establish.
