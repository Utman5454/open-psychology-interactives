# Simplified Interactives — Golden Reference Pack

These files are **reference exemplars**, not templates to copy mechanically.

Use them to infer the intended visual system, pacing, interaction density, feedback style, and synthesis behaviour for the new Simplified Edition.

## Shared design language

- warm off-white page background
- white rounded cards
- dark navy typography
- restrained teal / blue accents
- small gold highlights
- generous spacing
- modern university workbook feel
- brief setup and concise feedback
- strong visual synthesis only where it earns its place
- responsive layout and keyboard-usable controls
- roughly 3–7 minutes of learner work
- one clear teaching job per activity

## Interaction rhythm

Short setup → do something → notice something → brief explanation → visual synthesis.

Do not turn every activity into the same interaction. Preserve useful differences between prediction tasks, demonstrations, lens switches, evidence judgements, consequence chains, and recap activities.

## What each exemplar demonstrates

### unit4_prepare_quick_judgement_study_varied_counts.html
A light experimental / simulation pattern:
- learner acts before explanation
- minimal copy
- repeated trials
- end-of-task comparison
- concept revealed through experience rather than announced in advance

### unit5_prepare_identity_in_context_consequences.html
A contextual comparison pattern:
- same person across changing situations
- short decisions
- consequences of theory made explicit
- clean final synthesis

### unit6_consolidation_who_gets_to_define_the_story_aligned.html
A consequence-chain pattern:
- same event, different accounts
- authority / positioning matters
- second-order consequences develop over time
- avoids reducing the task to terminology matching

### unit8_consolidation_power_lens_laboratory_fixed_figure.html
A lens-switch pattern:
- one case stays constant
- theory changes what comes into focus
- each lens has strengths and blind spots
- avoids presenting one framework as universally correct

### unit9_prepare_what_did_the_measure_show_operationalisation.html
An evidence-and-inference pattern:
- operationalisation made explicit
- learner judges what a measure can support
- careful distinction between proxy, construct, behaviour and motive
- concise 'do not overclaim' feedback

### unit11_prepare_from_score_to_setting.html
A person-setting progression:
- measure outcome
- inspect context
- change setting
- explanation strengthens as evidence changes
- final diagram integrates measurement, cause and intervention

### unit12_prepare_six_questions_one_module_refined_v3.html
A recap / synthesis pattern:
- quick conceptual retrieval
- short, balanced answer options
- module architecture made visible
- final diagram summarises parallel shifts without inventing false causal links

## Rules for Claude

1. Treat these as **golden references** for the simplified edition.
2. Do not overwrite or refactor these files as part of the repository audit.
3. Do not assume every future activity should resemble the same exemplar.
4. Reuse the visual grammar and pacing, while selecting the interaction pattern that best fits each teaching job.
5. Preserve strong original simulations, diagrams, and demonstrations when simplifying the existing 75 tasks.
6. Avoid obvious “correct answer is longest” patterns and weak distractors.
7. Avoid long explanatory passages before the learner has done anything.
8. Theory should alter prediction, interpretation, evidence, or intervention.
9. The original interactives remain authoritative historical versions and must stay intact.
