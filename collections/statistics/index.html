Collection 01

Statistics

Interactives for the inferential ideas that students most often meet as formulae first and intuition second: how much a statistic moves from sample to sample, what uncertainty around an estimate actually means, and what a test statistic is responding to when it changes.

This collection has been set up but does not contain any interactives so far. When the first one is added it will appear here, and it will be linked from the home page at the same time.

Each interactive will live in its own folder under tools/statistics/ as a self-contained page, so it can be downloaded, used offline, or copied into your own course materials.

What this collection will cover

These are the topics the collection is being built around. None of them has been implemented yet; the list is here so you can see the intended scope, and so contributors know what is already spoken for.

  • Sampling distributions Repeatedly drawing samples from a known population and watching the distribution of the sample mean take shape — the single idea most of inferential statistics rests on.
  • Confidence intervals What the interval covers across repeated samples, and what it does not license you to say about the one study in front of you.
  • p-values and significance testing How a p-value responds to effect size, sample size and variability when each is varied on its own rather than together.
  • Correlation and regression Building a scatterplot point by point to see how outliers, range restriction and non-linearity move a coefficient that is usually reported as a single settled number.
  • Statistical power The trade-off between sample size, effect size and the chance of detecting an effect that is really there.

What each tool will include

  • A single idea, stated in one sentence at the top of the page.
  • Controls that change one thing at a time, operable by keyboard.
  • A visualisation, always paired with the same information in text.
  • Teaching notes: what to ask students, and the misconception the tool is designed to surface.
  • A reset button, so a demonstration can be run again cleanly in front of a class.

Building one of these

All five topics above are open. If you teach statistics and have a demonstration you already run by hand, turning it into a page here makes it reusable by everyone else. The contributing guide covers the file layout, the shared interactive shell and the accessibility checks a tool needs to pass before it is merged.
