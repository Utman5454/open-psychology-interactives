Collection 03

Neuropsychology

Interactives for brain–behaviour reasoning and the classic experimental paradigms, so that students can run the task and see their own pattern of responses before they read about the effect in a textbook.

In preparation — no interactives published yet

Nothing published yet

This collection has been set up but does not contain any interactives so far. When the first one is added it will appear here, and it will be linked from the home page at the same time.

Each interactive will live in its own folder under tools/neuropsychology/ as a self-contained page, so it can be downloaded, used offline, or copied into your own course materials.

What this collection will cover

These are the topics the collection is being built around. None of them has been implemented yet; the list is here so you can see the intended scope, and so contributors know what is already spoken for.

  • Classic attention tasks Runnable versions of Stroop-type interference and spatial cueing paradigms, with the student's own reaction times summarised once the block ends.
  • Working memory and span Span procedures that make the capacity limit something a student meets directly rather than reads about as a number.
  • Dissociation logic Single and double dissociations, and precisely what each one licenses you to conclude about separable processes.
  • Executive function Set-shifting and inhibition tasks, with the switch cost calculated from the student's own responses rather than quoted from a paper.
  • Interpreting deficits Why performance on any one task rarely maps onto a single region, and how case evidence accumulates into a claim.

What each tool will include

  • A single idea, stated in one sentence at the top of the page.
  • Controls that change one thing at a time, operable by keyboard.
  • A visualisation, always paired with the same information in text.
  • Teaching notes: what to ask students, and the misconception the tool is designed to surface.
  • A reset button, so a demonstration can be run again cleanly in front of a class.

A note on timed and animated tasks

Reaction-time paradigms are the hardest kind of interactive to make accessible, because the timing pressure that makes the task work is also a barrier for some students. Tools in this collection will offer a keyboard route through every task, an untimed practice mode, and a version of the underlying idea that can be explored without completing the task at all — so a student who cannot do the timed version still meets the concept.

Nothing here diagnoses or assesses anyone. These are demonstrations of paradigms, run on a laptop in uncontrolled conditions, and the tools will say so on the page.

Building one of these

All five topics above are open. If you teach neuropsychology and have a demonstration you already run by hand, turning it into a page here makes it reusable by everyone else. The contributing guide covers the file layout, the shared interactive shell and the accessibility checks a tool needs to pass before it is merged.
