# Teaching notes - Constructing a Category

`modules/social-critical-psychology/tools/02-constructing-a-category/`

**What it teaches.** Reification runs through a sequence of
individually reasonable decisions rather than one error or discovery:
selecting shared features, naming the pattern, drawing a numeric
threshold, building an instrument from the same features, then
institutional uptake. A prevalence figure reports where a line was
drawn; moving the threshold from one feature to six swings the figure
from 41% to 0% without a single simulated person changing.

**Before students start.** Read the six accounts aloud. The tool
tracks one fixed simulated population of 400 throughout every stage.

**What students do.**
1. Predict what will most determine the eventual prevalence figure.
2. Select at least three shared features, then name the pattern from
   six options and compare what each name imports before any data
   exist.
3. Set a feature threshold, plus duration and interference conditions,
   and watch prevalence move, then build a five-item instrument and
   read how much it overlaps with the features already chosen.
4. Work through five institutional decisions and watch an object-status
   index climb from a description someone wrote down towards an
   administrative fact.

**What to look for.** Not one of the 400 simulated people changes as
the threshold slider moves; only which bars count as meeting it. An
instrument built mostly from the features that already define the
category cannot fail to confirm those criteria, which is not evidence
of validity, only the criteria written twice.

**Debrief.** At which stage would a critic have needed to intervene to
stop the category hardening, given that no single stage involved a
factual error?

**Common misconception / caution.** Constructed does not mean
invented. Classification is how any science starts, and a threshold
has to sit somewhere if anyone is to be offered anything on the basis
of it. The caution runs the other way too: a prevalence figure quoted
without the threshold that produced it is not interpretable at all.

**Use in class / timing.** The worked example alone makes the point in
about 10 minutes. All five stages with the closing challenge run to
about 40.
