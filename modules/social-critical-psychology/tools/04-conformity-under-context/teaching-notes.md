# Teaching notes - Conformity Under Context

`modules/social-critical-psychology/tools/04-conformity-under-context/`

**What it teaches.** Conformity splits into two independent routes,
normative, wanting to avoid standing out, and informational, using
others as evidence about an ambiguous judgement. The same six presets
swing agreement from 7% to 67% depending on which route each condition
feeds. The normative route responds only to unanimity, audience and
identification; the informational route only to ambiguity and the
majority's standing, which is exactly what makes a private-response
manipulation diagnostic.

**Before students start.** Predict what proportion give the same wrong
answer as the group on the classic unanimous, spoken-aloud,
unambiguous version, before opening the lab.

**What students do.**
1. Predict the conformity rate on the classic condition.
2. Load a preset or set six situational controls and read the rate
   split into its normative and informational components.
3. Run 100 simulated participants at the current condition and read
   the distribution behind the group mean.
4. Classify five described manipulations as mainly normative, mainly
   informational, or both.

**What to look for.** Switching from a spoken to a private written
response nearly halves conformity almost entirely by cutting the
normative route, leaving the small informational component untouched.
Making the display genuinely ambiguous does the opposite: the
normative route is unchanged while the informational one inflates.

**Debrief.** What does the private-response manipulation actually show,
given which route it changes and which it leaves alone?

**Common misconception / caution.** Most rounds, in this model as in
the original studies, are still answered correctly: conformity is a
minority pattern on a minority of trials, not a description of most
behaviour. This activity models Asch-style pressure toward a stated
majority answer, not Sherif-style convergence on a genuinely ambiguous
judgement with no majority answer stated beforehand.

**Use in class / timing.** The worked example alone takes about 8
minutes. Both experiments with the closing challenge push the session
to about 45.
