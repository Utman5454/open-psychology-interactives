# Teaching notes - Assessment Battery Builder

`modules/neuropsychology/tools/11-neuropsych-assessment-battery-builder/`

**What it teaches.** A battery is chosen from the referral question,
not assembled by ticking everything on offer. The measures that answer
no referral question themselves, mood, effort, premorbid level, a
sensory screen, are the ones that make every other score
interpretable. A battery is judged on four things: converging evidence
in the domains the referral asks about, a domain expected to be
intact, the context measures this referral needs, and whether it fits
in one session.

**Before students start.** Predict which single addition would do
most for confidence in the conclusions, given one good memory test
already chosen.

**What students do.**
1. Answer the opening prediction.
2. Read a referral, then build a battery from seventeen tasks within a
   ninety-minute budget, or load a battery built to pass all four
   checks.
3. Take the closing challenge on what a single test score can and
   cannot establish.

**What to look for.** Ticking every task overshoots the budget by a
wide margin, while the pre-built battery passes all four checks in far
less time. Switching to a different referral without reselecting any
task leaves every number on screen unchanged but changes which checks
now pass.

**Debrief.** Put to the group what the four checks actually evaluate,
the design of the battery, and what they say nothing about, any
particular person's diagnosis.

**Common misconception / caution.** The closing challenge's report
says a recall score "indicating a significant memory impairment" came
from one task alone. "Indicating" is the word doing the damage: that
percentile can just as easily reflect poor sleep, low mood, pain,
medication, an unscreened hearing problem, or variable effort as a
genuine memory difficulty, and a single score cannot tell those apart
when none of the alternatives was measured.

**Use in class / timing.** A single battery, built against its own
referral, takes about 10 minutes. Cycling through all three referrals
and the challenge fills about 45.
