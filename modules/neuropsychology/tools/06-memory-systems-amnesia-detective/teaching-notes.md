# Teaching notes - Memory Systems Detective

`modules/neuropsychology/tools/06-memory-systems-amnesia-detective/`

**What it teaches.** A claim that two memory tasks do not depend on
all the same things is supported by a profile only when one measure is
clearly below its own control band while a comparable measure clearly
is not. Students judge three such claims against three fictional
profiles, then find that a fourth, mildly and evenly reduced profile
counts against every separability claim and supports a general
reduction in capacity instead.

**Before students start.** Predict what a normal immediate span and a
poor thirty-minute recall establish about memory, before the profiles
open.

**What students do.**
1. Answer the opening prediction.
2. For three profiles and three claims, judge whether each profile
   supports, counts against, or cannot decide each claim, reading
   every measure against its own control band.
3. Open a fourth profile once the first three are judged, then take
   the closing challenge on separating retrieval from storage.

**What to look for.** One profile supports both a short-term and
long-term separation and a facts-and-skills separation. A second
supports the short-term separation but not the skills one. The third,
mildly below average across every measure with nothing standing out,
counts against both separability claims and supports the general
reduction account instead. The fourth profile's lost word knowledge
drags down every measure that uses words, a confound the closing
challenge is built to catch.

**Debrief.** Ask why "separate systems" is one word too strong for
what the first profile alone establishes, compared with "do not depend
on all the same things."

**Common misconception / caution.** Recognition beating recall does
not by itself show the difficulty is at retrieval rather than storage;
it shows that only once the recognition test is made hard enough that
a control group would score the same on it as on recall. No anatomy
and no syndrome is named anywhere in this activity, on purpose: a
behavioural profile constrains what is going on, not where.

**Use in class / timing.** Judging one profile across all three claims
makes the point in about 8 minutes. All four profiles with the
challenge run to about 30 minutes.
