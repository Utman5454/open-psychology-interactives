# Teaching notes - Executive Function Task Laboratory

`modules/neuropsychology/tools/08-executive-function-task-laboratory/`

**What it teaches.** No task in this model is pure. Each of four tasks
loads on several of six capacities at once, so a single low score
cannot identify which capacity is reduced. The tool computes, live,
every other single-capacity reduction that would produce the same
lowest-scoring task, turning "which capacity is this" into a question
with more than one live answer rather than a claim the guide has to
assert.

**Before students start.** Read the "a transparent model, not a
measurement" panel aloud. Nobody performs these tasks; the weights are
an authored argument about what each task demands, written for
teaching.

**What students do.**
1. Predict what a below-range score on one task, alongside in-range
   scores on three others, identifies.
2. For each of four tasks, tick which of six capacities it needs
   before revealing the model's actual weights against your guesses.
3. Move six capacity sliders, or load a preset reduction, and read
   which task scores lowest and which other single reductions would
   give the identical result.

**What to look for.** No task's weight row has fewer than five
non-zero capacities. A reduction in processing speed alone can produce
the same lowest-scoring task as a reduction in inhibition alone, and
the interpretation box names every capacity that ties before students
have to work it out. The accuracy-or-speed slider pulls the two
component scores in opposite directions while their mean, the summary
score, never moves.

**Debrief.** Ask why "a selective impairment of response inhibition"
is not the safest reading of one below-range score, given what the
weight matrix shows about that task.

**Common misconception / caution.** The closing report to critique
claims a below-range colour-word score with three in-range scores
shows selective inhibition damage. A reduction in processing speed
alone reproduces the identical pattern. Naming a brain region is worse
still: executive tasks are impaired by damage in many places, and
frontal damage does not reliably impair them.

**Use in class / timing.** The opening question and one task's reveal
make the point in about 10 minutes. Both experiments with the closing
challenge run to about 45 minutes.
