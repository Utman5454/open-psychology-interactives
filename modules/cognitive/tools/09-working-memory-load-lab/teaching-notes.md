# Teaching notes - Working-Memory Load Laboratory

`modules/cognitive/tools/09-working-memory-load-lab/`

**What it teaches.** Working-memory decline under load is a curve, not a
fixed-capacity cliff, and a concurrent task from the same domain as what
is held costs far more than one from a different domain, even when both
concurrent tasks are matched for pacing. A residual cost even in the
mismatched pairing points to some domain-general component as well.

**Before students start.** The two concurrent tasks are matched for
pacing and number of judgements, not for difficulty. Mention that
before anyone compares them.

**What students do.**
1. Predict which combination of held material and concurrent task will
   hurt memory most.
2. Choose what to hold, letters or grid positions, and what to do while
   holding it.
3. Run two practice trials, then twelve trials spread across three
   loads.
4. Read the accuracy-by-load chart.
5. Change the concurrent task and run again to compare a same-domain
   cost against a different-domain one.
6. Sort five findings in the closing challenge.

**What to look for.** At the lowest load, the four combinations look
nearly identical. The gap opens up as load increases, and a same-domain
pairing, verbal material with a verbal concurrent task, costs far more
than a different-domain pairing at the same load.

**Debrief.** Why are the four conditions almost identical at the lowest
load? Even a mismatched concurrent task costs something. What is that
residual cost usually attributed to?

**Common misconception / caution.** Expect "the symmetry task is just
harder" as an objection. It is a fair worry, which is exactly why each
concurrent task is crossed with both materials: difficulty stays
constant while only the pairing changes. A single learner rarely
completes the full crossing in one sitting, so comparing results across
people needs care.

**Use in class / timing.** Six minutes is enough for a demonstration.
Two runs, a baseline and one concurrent task, take 12. A full session
with a third run, the challenge and the debrief runs about 30.
