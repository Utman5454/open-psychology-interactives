# Teaching notes - Visual Search Laboratory

`modules/cognitive/tools/02-visual-search-laboratory/`

**What it teaches.** Searching for a target defined by one feature stays
nearly flat as more items are added. Searching for a target defined by a
conjunction of two features gets much slower with every item added, in the
same person, on the same screen.

**Before students start.** Three trials per condition is a
demonstration of what the design does, not a stable estimate. Say so
before anyone compares slopes.

**What students do.**
1. Predict whether set size will slow both kinds of search equally.
2. Use the untimed inspection panel to look at displays before timing
   anything.
3. Run practice, then two scored blocks, one feature search and one
   conjunction search, or load the worked example instead.
4. Read the fitted slope for each condition, present and absent trials
   kept separate.
5. Sort five claims in the closing challenge.

**What to look for.** The worked example gives feature slopes of about
2.7ms and 3.9ms per item (present and absent trials) against conjunction
slopes of about 22ms and 45ms, an eightfold to twelvefold difference
within the same worked example. In both conditions the absent slope is
the steeper of the pair, not only in this example.

**Debrief.** Why is the absent slope always steeper than the present
slope, within each condition? The worked example's two-to-one ratio of
absent to present trials was built into the generator, not discovered by
it. Why does the tool tell you that?

**Common misconception / caution.** "Feature search is parallel,
conjunction search is serial" is the standard shorthand, but the tool
only gives two slopes. A steep slope is just as consistent with a slower,
limited-capacity process as with checking items one at a time. Three
trials per condition is a demonstration, not an estimate; the worked
example's fourteen trials per cell is the more trustworthy pair of
numbers.

**Use in class / timing.** A front-of-room demonstration with the worked
example runs about 8 minutes. Both scored blocks with the challenge and
debrief take 30 to 35 minutes.
