# Teaching notes - False Memory and Source Monitoring

`modules/cognitive/tools/10-false-memory-source-monitoring/`

**What it teaches.** Recognition, confidence and source attribution are
three separable judgements that can disagree. A thematically related
lure word can be falsely "recognised" with genuine confidence because it
fits a list's gist, yet still fail source attribution, since source is
inferred at retrieval rather than retrieved as a stored tag.

**Before students start.** This is a specific, constrained intrusion,
not a general claim that memory cannot be trusted. Unrelated new words
are rarely mistaken for something studied; related lures are a
different story.

**What students do.**
1. Predict which judgement, source, recognition or confidence, will be
   hardest to get right.
2. Choose a study pace and study 24 words, each labelled with one of
   two sources.
3. For each of 12 test words, say whether you saw it and how sure you
   are, then, if yes, which source it came from.
4. Read the three-row results: how often each item type was endorsed,
   at what confidence, and how often source was correct.
5. Sort five findings in the closing transfer challenge.

**What to look for.** In the worked example, a related lure gets
endorsed as "seen" 61% of the time, nearly as often as genuinely studied
words at 84%, and with real confidence attached, while an unrelated new
word is endorsed only 9% of the time. Source accuracy, 71%, sits below
recognition accuracy, showing the two judgements do not rise and fall
together.

**Debrief.** What did the words on the list have in common with the word
you falsely recognised? Is that a coincidence? Source accuracy is lower
than recognition accuracy. Why would that be, if source were simply
stored alongside the item?

**Common misconception / caution.** "This proves memory is unreliable"
goes further than the evidence supports: the intrusion is tightly
constrained to words that fit the list's theme. An unrelated word is
endorsed only 9% of the time in the worked example, against 61% for a
related lure, which is exactly why the unrelated condition works as the
comparison. Once a student has run this once, forewarning reduces false
endorsement, so a second theme set is for a fresh demonstration, not
for practice.

**Use in class / timing.** Plan on 6 minutes for a demonstration. One
study-test cycle takes 8 to 10. With the challenge and the debrief,
about 25 minutes total.
