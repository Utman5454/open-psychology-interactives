# Teaching notes - Posner Spatial Cueing

`modules/cognitive/tools/01-posner-spatial-cueing/`

**What it teaches.** A cue students are told to ignore still shifts
attention: valid cueing speeds responses and invalid cueing slows them,
both measured against a neutral, uninformative baseline. A single
valid-versus-invalid number hides which of those two things actually
happened.

**Before students start.** Remind students this measures browser
reaction times, not attention as a trait. The cue is genuinely
uninformative, and they are told to ignore it.

**What students do.**
1. Predict whether valid cueing helps, invalid cueing hurts, or both.
2. Run six practice trials, then a scored block, or load the worked
   example instead.
3. Read the benefit (neutral minus valid) and the cost (invalid minus
   neutral) as two separate numbers.
4. Classify four fictional studies in the closing challenge.

**What to look for.** In the worked example, valid trials run 28ms faster
than neutral and invalid trials run 52ms slower, so the cost outweighs the
benefit. In a student's own default 48-trial block, invalid trials are
deliberately the rarest condition, as few as eight of them, so one slow
response can swing that mean a long way.

**Debrief.** Someone in the room will get a negative benefit, valid slower
than neutral. Does that count against the effect? Eight trials is not an
estimate. What would you need before treating it as one?

**Common misconception / caution.** Expect someone to say this proves
attention moved without their eyes moving. It does not: there is no
eye-tracking here, so an unnoticed glance toward the cue explains the
result just as well as covert attention does. Treat any one person's
invalid mean as a rough guide, not a measurement.

**Use in class / timing.** The worked example alone runs in about 6
minutes. A full session with one scored block, the challenge and the
debrief takes 25 to 30 minutes.
